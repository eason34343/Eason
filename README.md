# Eason Su — Independent Web Design

A local, bilingual, one-page portfolio/service-site draft created for the website-design activity in the college application. The Projects section includes the local pet-care business website and the OneStep clickable prototype.

## Preview

From this directory, run `python3 -m http.server 8765`, then open `http://localhost:8765/`.

The site has no build step or backend. It works on desktop and mobile. The English/繁體中文 toggle remembers the visitor's choice locally.
